# Adapter — gentle-ai

How the overlay binds to gentle-ai's real, documented seams. The core (`VISION`, `PHASE-LENS`,
`INTENT-CONTRACT`) is host-agnostic; only this file knows gentle-ai. If a gentle-ai update changes a
seam, only this file changes.

## Seams we depend on

| Seam | What it is | How the overlay uses it |
| --- | --- | --- |
| Project `AGENTS.md` | gentle-ai reads it as the project activation boundary | **Primary injection point.** The installer adds the overlay activation block here. |
| Skill registry (`.atl/skill-registry.md`) | auto-generated index; the orchestrator injects matching `SKILL.md` paths into each subagent | **Read-only for us.** `clean-code-standards` is already registered, so the quality lens already reaches subagents. We do NOT write here — it is regenerated by `gentle-ai skill-registry refresh --force`. |
| Engram SDD topics (`sdd/{change}/...`) | per-phase artifacts persisted across the chain | The Intent Contract lives at `sdd/{change}/intent`; phases read it and write their `Intent Gate` line. |

> **Why not the registry?** It carries an `Auto-generated` header and is rebuilt from scanned skill
> directories. A manual row would be erased on the next refresh. `AGENTS.md` is durable and reversible,
> so it is the single wiring point.

## What the installer writes to AGENTS.md

A single marker-delimited block (idempotent, reversible):

```
<!-- intent-overlay:start -->
## Intent Overlay (active)

Before any SDD chain, freeze an Intent Contract per `overlay/INTENT-CONTRACT.md` at the engram topic
`sdd/{change}/intent`. Do not write code until the human freezes it.

Pass these overlay paths to EVERY SDD phase, and apply them through `overlay/PHASE-LENS.md`:
- `overlay/VISION.md`
- `overlay/PHASE-LENS.md`
- `overlay/INTENT-CONTRACT.md`

Every phase emits `Intent Gate: aligned | drift-detected`. Code phases also emit the Clean Code Gate
at refactor-exit. `drift-detected` halts the chain and returns to the human as a change request; it is
never applied silently.
<!-- intent-overlay:end -->
```

## Commands

- `install.sh install [DIR]` — add the block to `DIR/AGENTS.md` (default: current dir). No-op if present.
- `install.sh uninstall [DIR]` — remove the block, leaving the rest of `AGENTS.md` byte-identical.
- `install.sh doctor [DIR]` — verify the seams: `AGENTS.md` exists and is writable, the overlay docs
  exist, and `clean-code-standards` is present in the registry. Non-zero exit if a seam is missing.
- `install.sh --direct` — standalone mode (no host). **Deferred in v1**: prints a not-implemented notice.
